# Author's PARAPHRASE of RFC 1122 section 4.2.2.13 (not the RFC text; see SOURCES.md and MODELLING.md)
[I-01] A host MUST NOT implement a half-duplex close.
[I-02] If a host with half-duplex close closes the connection while received data is still pending, its TCP SHOULD send a reset to show the data was lost.
