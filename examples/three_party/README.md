# three_party
A coordinator addresses two participants (`!DATA@P1`, `!DATA@P2`). Both participants run the same role, so reading choices are made per implementation: mixed and common-mode profiles now arise between implementations of the SAME role. Mailbox semantics: one FIFO mailbox per implementation, sender identity not tracked.

_Synthetic fixture: an engineered test case for the mechanism above, not evidence from real protocols._
